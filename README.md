# Blokus Premium (オンライン4人対戦ブロックス)

高品質なビジュアルデザインと自動パス判定、COM（AI）自動補填、さらにリアルタイム通信対戦を搭載した、ブラウザで動作するプレミアムな4人対戦型ブロックスゲームです。

---

## 🌟 特徴
- **2つのプレイモード**:
  - **オンライン対戦 (4人)**: ルームIDを共有することで、遠隔地のプレイヤー同士で最大4人でリアルタイムに対戦できます。人数が不足している場合は、自動的にコンピュータ（COM）が空きスロットに入ります。
  - **練習戦 (VS コンピュータ)**: オフラインでCOM3人と手軽に対戦練習ができるモードです。COMの人数は1人〜3人まで調整可能です。
- **プレミアムなUI/UXデザイン**:
  - **ネオンエフェクト**: 各プレイヤーのテーマカラー（青・黄・赤・緑）に合わせた美麗な発光ネオンブロック。
  - **ガラスマフィズム**: 半透明のすりガラスの質感を取り入れたモダンなパネル構成。
  - **快適な操作性**: キーボードショートカット（Rキーで回転、Fキーで反転）に対応し、マウスホバー時にボード上にリアルタイムに配置可能性をプレビューします。
- **レスポンシブ対応**:
  - PCの大画面からスマートフォンの縦長・横長画面まで、比率を維持したまま自動で最適な大きさにスケールします。

---

## 🎮 操作方法
1. **ピースの選択**: 画面下部のパレットからピースをクリックして選択します。
2. **ピースの変形**: ピース選択中に **[R]キー** を押すと時計回りに90度回転、**[F]キー** を押すと左右に反転します（操作パネルのボタンをクリックしても操作可能です）。
3. **ピースの配置**: ボード上で置きたい位置にマウスカーソルを合わせ、クリックして確定します。配置可能な場合は緑色、不可能な場合は赤色のプレビューが表示されます。

---

## 📝 ゲームルール
- 各自の最初の1手は、ボードの4隅（各自のスタート位置）のいずれかのマスを必ず1マス以上カバーするように置く必要があります。
- 2手目以降は、自分の色のピースと **「角（斜め）」** でのみ接するように置かなければなりません。**「辺（上下左右）」で隣り合って接することは禁止**されています。他人のピースとは辺で接しても構いません。
- 置けるピースがなくなったプレイヤーは自動的にパス扱いとなります。
- 全員が置けなくなったらゲーム終了です。
- 置いたピースの総マス数（1マス1点）が多いプレイヤーが勝利となります（ペナルティルール：残ったマスの合計が最も少ないプレイヤーの勝ち）。
  - すべてのピースを置いた場合は +15 点のボーナス。
  - さらに、最後に置いたのが1マスのピース（モノミノ）だった場合は +20 点のボーナス。

## 🚀 起動方法
本アプリケーションは HTML, CSS, JavaScript のみで構成されているため、特別なサーバー側のインストールは不要です。

1. このフォルダ内の `index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップします。
2. もしくは、ローカルサーバー（VS CodeのLive Server、または Python の `python -m http.server 8000` など）を起動してアクセスします。

## 🛠️ GitHubへの登録とインターネット公開手順
※ ユーザー名は `kenken6291` を使用します。

### 1. GitHub上で新しいリポジトリを作成
1. [GitHub](https://github.com/) にログインします。
2. 画面右上の「**+**」アイコンをクリックし、「**New repository**」を選択します。
3. **Repository name** を `blokus-premium` にします。
4. 公開範囲を「**Public**」に設定します。
5. 「Initialize this repository with:」の項目はすべて**チェックを入れずに空欄のまま**にします。
6. 「**Create repository**」ボタンをクリックします。

### 2. リポジトリをGitHubに接続してプッシュする
```bash
git init
git branch -M main
git remote add origin https://github.com/kenken6291/blokus-premium.git
git add .
git commit -m "Initial commit of Blokus Premium"
git push -u origin main
```

### 3. インターネット上に無料公開する（GitHub Pages）
1. GitHubの `blokus-premium` リポジトリページにアクセスします。
2. 上部タブの「**Settings**」をクリックします。
3. 左メニューの「**Pages**」をクリックします。
4. 「Build and deployment」の中の **Source** を「**Deploy from a branch**」にします。
5. **Branch** で `main` を選択し、「**Save**」をクリックします。
6. 数分待つと、画面上部に公開されたURL（例: `https://kenken6291.github.io/blokus-premium/`）が表示され、友人と通信対戦ができるようになります！

## 🌐 オンライン対戦（Firebase）のセットアップ
オンラインマルチプレイを使用するためには、Firebase Realtime Database の初期設定が必要です。
接続用設定値を `app.js` の先頭（`firebaseConfig`）に記述することで動作するようになります。
※ 既存の設定値がすでに書き込まれているため、そのままでもお試しいただけます。
